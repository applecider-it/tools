セレニウム起動

railsでは、システムテストでセレニウムが動くので、これは不要

rails以外でseleniumを使いたいときは、これを使う

複雑な導線のJSフレームワークの実装時では、これを使うと便利


cd ~/workspace/github/tools/selenium

source venv/bin/activate

python -m app.entrypoints.main sample

python -m app.entrypoints.main sample2

----

ログイン

python -m app.entrypoints.main

通常のログインをすると、状態が維持される
